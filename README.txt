DIVINE YATRA — WEBSITE FILES

Files:
- index.html            Home page, destinations, trip enquiry form
- trip.html             Detailed itinerary page for each destination
- payment.html          Payment-method selection step (demo only)
- booking-success.html  Order summary and estimated payment breakdown

HOW TO RUN:
1. Keep all four HTML files in the same folder.
2. Open index.html in a browser, or open the folder in VS Code.
3. Choose a trip, fill in the form, select a payment method on the next page, then submit.

PAYMENT NOTE:
This website is a front-end demo. It records a selected payment method only; it does NOT charge money or connect to Google Pay, a bank, card network, or payment gateway. Do not enter card details, CVV, UPI PIN, OTP, or bank passwords. To accept real payments, integrate a trusted payment gateway and verify payment server-side before marking an order paid or confirmed.

Prices and itineraries are illustrative and must be confirmed. The latest booking is stored only in the current browser's localStorage.
